THIS IS A WALLPAPER ENGINE RUNNING ON PYTHON TKINKER THAT LETS YOU CHOOSE AN IMAGE ON YOUR COMPUTER DEVICE AND USE IT AS A WALLPAPER. IT ALSO LETS YOU REMOVE THE WALLPAPER .


### HOW TO RUN ###

1. INSTALL VISUAL STUDIO CODE :  https://code.visualstudio.com/

2. INSTALL PYTHON INSTALL MANAGER :  https://www.python.org/downloads/

3. ON VISUAL STUDIO DOWNLOAD THE PYTHON EXTENSIONS THAT ARE NEEDED
